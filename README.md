# حرف

منصة عربية لتوثيق رحلة القراءة ومشاركة الآراء حول الكتب.

🔗 **[تجربة الموقع](https://harf-orcin.vercel.app)**

---

## عن المشروع

"حرف" مساحة يوثّق فيها القارئ ما قرأه وما ينوي قراءته، ويشارك رأيه حول الكتب،
ويتفاعل مع آراء غيره من القرّاء.

## المزايا

- **مكتبة الكتب** — تصفّح وبحث وتصفية حسب التصنيف، بكتب عربية وإنجليزية
- **صفحة لكل كتاب** — تفاصيل الكتاب ومساحة لآراء القرّاء
- **المراجعات والتفاعل** — كتابة الآراء والتقييم بالنجوم والإعجاب والردود
- **مكتبتي** — رفوف شخصية مع متابعة تقدّم القراءة وسلسلة الأيام
- **المجتمعات** — دوائر نقاش حسب التصنيف وترشيحات الكتب
- **جلسات القراءة الصامتة** — جلسات جماعية بمؤقت مباشر

## التقنيات

- React + Vite
- Tailwind CSS
- خط ثمانية
- localStorage لحفظ البيانات على جهاز المستخدم
- النشر عبر Vercel

## التطوير القادم

- ربط قاعدة بيانات Supabase للمصادقة وحفظ البيانات على السحابة
- مزامنة مكتبة المستخدم ومراجعاته عبر الأجهزة
- تفعيل جلسات القراءة الجماعية بشكل لحظي عبر Supabase Realtime

## التشغيل محليًا

```bash
npm install
npm run dev
```
